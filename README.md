# GROOVE

Geometry-Guided Reduction of Operational-Space Jerk in VLA Execution

Sangho Yun, Minsoo Kim, Minwoo Cho, and Hwanjo Yu — POSTECH

[Project page](https://devsangho.github.io/GROOVE-public/) ·
[VLA jerk paper on arXiv](https://arxiv.org/abs/2609.13695) ·
[Paper PDF](https://arxiv.org/pdf/2609.13695)

GROOVE is an online **VLA jerk reduction** method for smoother robot execution.
It reduces within-chunk and chunk-boundary jerk in vision-language-action (VLA)
policies without retraining or additional policy inference.

This repository hosts the static project website, interactive method animation,
demonstration videos, and public manuscript. Code, evaluation scripts, and
experiment artifacts will be released upon publication.

The website is published by GitHub Pages from the root of the `main` branch.
