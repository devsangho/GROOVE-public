# GROOVE

Geometry-Guided Reduction of Operational-Space Jerk in VLA Execution

[Project page](https://devsangho.github.io/GROOVE-public/) ·
[Paper PDF](https://devsangho.github.io/GROOVE-public/static/paper/groove.pdf)

This repository hosts the static project website, interactive method animation,
demonstration videos, and public manuscript. Code, evaluation scripts, and
experiment artifacts will be released upon publication.
